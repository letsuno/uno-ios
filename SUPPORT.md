# Support

Use [GitHub Issues](https://github.com/letsuno/uno-ios/issues) for reproducible client bugs and compatibility problems. Include the app version, iOS or iPadOS version, device model, server version, and reproduction steps.

Questions about deploying or operating the server belong in the [UNO Online repository](https://github.com/letsuno/uno-online).

Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).
